# Redux Learning 🚀

A dedicated repository for practicing and mastering different Redux topics through examples and small projects.

## 🎯 Objectives
- Understand core Redux concepts and data flow.
- Practice **Redux Toolkit (RTK)** for modern, boilerplate-free state management.
- Implement **RTK Query** for efficient data fetching and caching.
- Integrate Redux with both **React (Vite)** and **Next.js** architectures.
- Build real-world state management scenarios and mini-projects.

## 📂 Repository Structure
This repository acts as a monorepo-style workspace for various sub-projects. Each folder will contain a specific topic, example, or mini-project. 

Projects will utilize:
- **React + Vite** for lightweight Single Page Applications (SPAs).
- **Next.js** for Server-Side Rendered (SSR) and full-stack React applications.

## 🛠️ Tech Stack
- **State Management:** Redux, Redux Toolkit (RTK), RTK Query
- **Frameworks/Libraries:** React, Next.js
- **Build Tools:** Vite
- **Languages:** JavaScript / TypeScript
